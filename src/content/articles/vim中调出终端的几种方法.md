# 在vim中打开一个内置终端

命令：

```
:term
或
:terminal
```

用于启动一个内置的终端模拟器，进入到vim的终端模式。这个命令允许用户在 Vim 编辑器中直接运行一个交互式的 shell 或其他终端程序，而无需离开 Vim 环境。这在需要同时编辑文件和运行终端命令时特别有用。
