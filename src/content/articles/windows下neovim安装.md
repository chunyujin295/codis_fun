# 安装NeoVim

参考链接：[零基础在Windows环境下配置neovim+Lazyvim_neovim windows-CSDN博客](https://blog.csdn.net/qq_74043043/article/details/142267682)

进入neovim官网[Home - Neovim](https://neovim.io/)点击install或者直接进入其GitHub的release发布页面[neovim/INSTALL.md at master · neovim/neovim](https://github.com/neovim/neovim/blob/master/INSTALL.md)

<div><center><img src="https://map--depot.oss-cn-hangzhou.aliyuncs.com/image/image-20250208005407848.png" alt="image-20250208005407848"/><br>安装Windows的发布版本</center></div>

点击之后下载`.msi`安装文件，下载完成后双击进行安装，记得安装在自己能找到的位置。

安装成功之后就可以在终端打开neovim：

```bash
nvim
```

如果能打开就说明安装成功
